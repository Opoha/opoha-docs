# Contributing to Opoha Docs

Thanks for helping improve [opoha-docs](https://github.com/Opoha/opoha-docs).

## Scope

- Public developer documentation for the Opoha ecosystem.
- Keep examples aligned with published package APIs (`@opoha/core`, `@opoha/cli`, `@opoha/create-opoha`, plugins).
- Do **not** embed real secrets in docs or sample snippets — use placeholders and `.env.example` patterns.

## Local development

Follow the repository README for the docs site toolchain (install, preview, build). Prefer small, focused PRs with a clear audience (getting started, plugin authoring, GraphQL, etc.).

## Ecosystem context

Org-wide notes: [CONTRIBUTING](https://github.com/Opoha/.github/blob/main/CONTRIBUTING.md). Architecture and planning: [opoha-workspace](https://github.com/Opoha/opoha-workspace).
